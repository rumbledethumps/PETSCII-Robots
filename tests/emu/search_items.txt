# What a search gives, and only that.
#
# SEARCH_OBJECT gives a pistol's ammunition, a plasma gun's, medkits or magnets,
# then, in the original, goes on into the next kind's CMP with whatever A the
# display routine left: the X16 and the PET fall through from all three of the
# first. src/game/items.s returns instead. While that A never matches, nothing
# shows the difference -- tests/source/verify_source.py checks the
# returns are there -- so this holds what each find gives: its own, and
# nothing of the kinds after it.
#
# level-a hides a hundred rounds for the pistol in slot 51, at 20,36, whose
# search box reaches the crate one square up from 21,38. tests/emu/search.txt
# finds it. Here the slot is hidden again as each of the other three kinds,
# with the same hundred, and searched again.
