# Amiga

Art from the Amiga version of *Attack of the PETSCII Robots*: the Amiga port by
Vesa Halttunen, with art by Piotr Radecki, under the Creative Commons
Attribution 4.0 licence. The files are from the `Amiga/` folder of
[zeropolis79/PETSCIIRobots-Amiga](https://github.com/zeropolis79/PETSCIIRobots-Amiga),
unchanged.

| File | What it is | Read by |
|---|---|---|
| `tiles.png` | The 253 tiles, 24×24. | `conv_amiga.py` |
| `animtiles.png` | The 24 frames of the animated tiles. | `conv_amiga.py` |
| `items.png` | The weapon and item pictures for the HUD. | `conv_amiga.py` |
| `health.png` | The health faces. | `conv_amiga.py` |
| `keys.png` | The three key cards. | `conv_amiga.py` |
| `gamescreen.png` | The game screen's frame. | `conv_amiga.py` |
| `introscreen.png` | The intro screen, for its palette and the corner the title's logo covered. | `conv_amiga.py`, `clean_title.py` |
| `gameover.png` | The game-over picture. | `conv_amiga.py` |
| `C64Font.raw` | The font. | `conv_amiga.py` |

The tests read them too.
